Welcome to the **Forza Motorsport 5 PC Port** repository. This project aims to make the classic Xbox One title playable on modern Windows PCs, powered by the **Race One Hub**.

## ✨ Features

* **PC Compatibility:** Run the original Xbox One game on Windows.
* **Race One Hub:** Clean and intuitive UI for building and managing the game.
* **Unlocked Framerates:** Experimental 120 FPS support available.
* **Custom Settings:** Adjustable video, audio, and language configurations.

---

## 🚀 Installation & Usage

1. Navigate to the [Releases](https://github.com/AdrianFawkes/fm5-port/releases) page.
2. Download the latest `.zip` archive from the Assets section.
3. Extract the contents into a dedicated folder (avoid system folders like `Program Files` to prevent permission issues).
4. Run the **Race One Hub** executable.
5. Configure your settings and click on **BUILD EXE**.
6. Launch the game and enjoy!
